## Проекты

**[NLP Vacancies Ranking](https://github.com/AIra-work213/NLP_vacancies_ranking)**: поиск вакансий по ключевым словам и смыслу. Объединил BM25 и E5 через RRF, сделал API на FastAPI, хранение в PostgreSQL/pgvector и кеш в Redis. На тестовом наборе из 12 запросов получил **NDCG@10 0,901 против 0,855 у BM25**. [Как устроена оценка](https://github.com/AIra-work213/NLP_vacancies_ranking/blob/main/docs/evaluation.md)

**[HackChange MWS Tables](https://github.com/AIra-work213/HackChange_MWS_tables)**: командный хакатон, призовое место. Разрабатывал LLM-агента для анализа постов ВКонтакте: агент обращается к данным через инструмент и строит ответ на основе полученного результата. В репозитории есть [код агента](https://github.com/AIra-work213/HackChange_MWS_tables/blob/main/server/model.py) и API

**[ML Salary Predictor](https://github.com/AIra-work213/ML_salary_predictor)**: прогноз зарплаты по тексту вакансии на основе RuBERT. Подготовил обучение модели и сервис на FastAPI, запуск через Docker. [Код обучения](https://github.com/AIra-work213/ML_salary_predictor/blob/master/training/train.py)
